# Onboarding session overview

This session walks new contributors through the full contribution flow in this sandbox repo.

## What we cover

- Creating a feature branch off `main`
- Writing commit messages that reviewers can follow
- Opening a pull request and describing the change
- Reviewing a PR: inline comments, review summaries, and Copilot code review
- Watching CI run in GitHub Actions

Nothing here is production code - this repo exists only for the demo, so it's safe to break things.
